# Projeto Login
Projeto desenvolvido como parte do curso de HTML e CSS do Curso em Vídeo, disponível no Youtube. O objetivo é praticar a estilização de formulários, aplicando conceitos como organização de layout e responsividade, simulando uma tela de login.
